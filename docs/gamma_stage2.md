# 湿潤γの第二段階ベースライン

実行：`python -m module.gamma_stage2 --config config/gamma/stage2.json`

説明変数は `config/gamma/stage2.json` の `numeric_features` と `categorical_features` で変更します。比較ごとに `output` を別ディレクトリに変更してください。追加する列は入力CSVに用意する必要があります。SolphyJ・地質情報の取得・処理は実装していません。

## 修正前の確認

- 第一段階：実測280件からB/C/Dを学習し、D優先で疑似815件を作成。統合CSVは1,095件。
- D優先の第二段階は未実装。過去の第二段階は粒度・含水比単独で作った疑似値による実験。
- 過去の粒度条件の空間評価：学習559件（実測156＋疑似403）、検証58件、テスト58件。R²=-0.0213、RMSE=1.3338、MAE=1.0160。
- 過去の含水比条件の空間評価：学習706件（実測158＋疑似548）、検証60件、テスト58件。R²=-0.3210、RMSE=1.5169、MAE=1.1677。
- 本番γ設定は予測N・地質等を含み、地点分割主評価のため、今回の位置・標高のみのベースラインとは一致しない。
- 保存済み疑似値は全実測で第一段階を再学習した出力であり、そのまま分割するとテスト目的変数の間接リークが起きる。

このため、評価時の疑似値再生成と、全データによる最終モデルの学習を分ける構成をユーザー確認のうえ実装しました。本番の分布生成処理は変更していません。

## データフロー

1. 保存済み統合CSVから実測280件と疑似候補815件を識別。
2. **実測だけ**を学習・検証・テストに分割。主評価は既存の10 kmブロック方式、参考評価は地点分割。
3. 学習実測の内部でさらにグループ分割し、第一段階B/C/Dの木の本数を選択。その後、外側の学習実測全体でB/C/Dを再学習。
4. 検証・テスト地点の疑似候補を除外。空間評価では検証・テストブロックも除外。保存済みの疑似目的変数を破棄し、D優先で再予測。
5. 外側の学習実測＋再生成疑似γを同じ重みで第二段階XGBoostに入力。説明変数はx・y・elevationのみ。
6. 外側の検証実測で第二段階の木の本数を選択し、テスト実測でR²・RMSE・MAEを算出。実測のみの比較モデルも同じ分割で評価。
7. 評価後、保存済みの実測280＋疑似815件すべてで最終モデルを学習。木の本数は主評価5回の検証選択値の中央値（24）。この最終モデル自体に独立テストスコアは付けない。

分割seedは42〜46。同一試料が複数回テストに含まれる反復ホールドアウトであり、通常の5-fold CVではありません。分割比率はブロック／地点数の比率で、行数の比率ではありません。

## 評価結果

5回の算術平均。RMSE・MAEの単位はkN/m³。

|評価|モデル|R²|RMSE|MAE|
|---|---|---:|---:|---:|
|空間（主評価）|実測のみ|−0.0739|1.4355|1.1052|
|空間（主評価）|D優先・同じ重み|−0.5270|1.6907|1.2897|
|地点（参考）|実測のみ|0.0910|1.4116|1.0497|
|地点（参考）|D優先・同じ重み|−0.0888|1.5469|1.1523|

現状の位置・標高だけのモデルでは、疑似γの等重み追加は平均精度を改善しませんでした。空間評価の追加モデルR²の分割間標準偏差は0.5546です。

## リーク確認と解釈の範囲

- 評価用第一段階の学習・早期停止に外側の検証／テスト目的変数を使わない。
- 評価用疑似γは毎回再生成し、全データ学習済みの疑似値を再利用しない。
- 学習と検証／テストの孔ID・同一座標、空間評価のブロック重複を検査。各実行の`leakage_audit.json`に記録。
- 第一段階内部の学習・検証IDも保存し、外側の学習実測に限定されることを追跡可能にした。
- **過去の実験では同じ実測データを使ってD優先の方針を選んでいるため、今回の結果は完全に未使用の外部データによる最終検証ではない。** 今回防いだのは各評価実行内の目的変数リークであり、過去のモデル選択履歴そのものを取り消すものではない。
