設定はconfig/gamma/n_comparison.json。enabled=trueでγの実行時に比較を追加します。
config/gamma/prediction.jsonのcreate_distribution=falseにすると、比較だけを行います。
`python run_analysis.py --targets gamma` で収集確認→整理→比較を実行する構成です。
今回は解析・学習・テストを実行していません。既存結果は今回のコードによる結果ではありません。

## 実測N値の対応

同じ平面位置を初期値0.01mの許容距離で検索します。複数孔が候補になる場合は自動選択せず欠損にします。
密度試料の採取区間内のSPTを用い、複数あれば上限50で処理したN値の平均を取ります。
これは試料中央での点測定ではなく区間代表値です。区間不明の場合のみ中央深度と一致する測定を使います。
深度許容差0.000001mは丸め誤差用です。近傍採用のために広げないでください。
区間内に値がない場合、近傍深度は診断用に記録するだけで採用しません。土層判定・近傍補完・補間は未実装です。
深度は各孔の地表からの深さを使用します。地表標高や深度基準の不一致が判明した場合は対応前に修正が必要です。

主要データ＝対応する実測N値がある密度試料。補助データ＝実測密度はあるがN値は推定する試料。
信頼性指標は補助データとは別の列です。

data/training/gamma/n_matching.csvに測定深度・件数・番号・対応方法・深度差を保存します。
同じ位置に複数XMLがある場合も、XY距離で連結した地点を同じグループとして分割します。
比較対象はγの前処理を通過した試料であり、生XMLの全184地点が必ず含まれるわけではありません。

## 比較条件

| scenario | γ学習時のN値 | 評価時のN値 |
|---|---|---|
| no_n | 使用しない・主要試料のみ | 使用しない |
| measured_n | 実測・主要試料のみ | 実測（N値既知条件） |
| measured_to_predicted_n | measured_nと同じ学習済みモデル | 推定 |
| predicted_n | 学習用孔を除いて推定・主要試料のみ | 推定 |
| predicted_n_reliability | 推定N値＋信頼性指標・主要試料のみ | 推定N値＋信頼性指標 |
| measured_plus_supplemental | 主要試料は実測、補助試料は推定 | 推定 |
| no_n_with_supplemental | N値を使わず主要＋補助試料 | 使用しない |

乾燥・湿潤それぞれ、同じ分割・同じ主要評価試料でMAE/RMSE/R²を比較します。
補助試料を加える条件以外は学習試料も同じです。主要評価試料数が不足すれば未完了として記録します。
measured_nとmeasured_to_predicted_nは木数選択も含め同一モデルで、入力の置換による差を測ります。
その他は各条件のvalidationで木数を決めます。supplemental_weightの初期値は1.0（同じ重み）です。
重みを変える場合もtestで選ばず、validationで検討してください。

## N値推定・信頼性

既存の全孔学習済みN値モデルや格子ファイルは比較に使用しません。
元SPTから共通の地理説明変数を構築し、φと同じ特徴量設定・XGBoostパラメータで別モデルを学習します。
RBFなど目的値由来の特徴量は未対応で、選択されていれば明示的に停止します。

γのvalidation・test孔（空間評価では地域内全孔）をN値モデルから除外します。
γ学習試料の推定N値も交差適合で作り、問い合わせ孔・地域のSPTを除きます。
N値モデル内部では学習・木数調整・区間校正を分離します。
木数調整後は学習＋調整部分で再学習し、校正データはモデル学習に戻しません。
乾燥・湿潤でN値推定結果を共有します。

保存する指標：N推定値、3つのseedモデル間標準偏差、校正誤差の90%分位に基づく上下限と幅、
最寄り学習地点までの距離、1km内の地点数、最寄り地点のSPT深度差、学習深度範囲外フラグ。
予測区間は空間相関を考慮した被覆保証ではなく、誤差に基づく経験的区間です。
共通test試料で実測N値を含む割合を報告します。局所的に区間幅を校正する処理は未実装です。

## 採用モデル：predicted_n

config/gamma/prediction.jsonのdistribution_modelをpredicted_nに設定しました。
主要試料のみを対象に、全主要試料の交差適合による推定N値で乾燥・湿潤γを再学習します。
補助試料・信頼性指標は説明変数に加えません。木数は主評価モードのpredicted_nのvalidationで決めた値を使います。
N値モデルはφの特徴量設定・パラメータ・複数seedの平均・上限50を使用します。
全域予測用N値モデルも校正データを学習から外し、同モデルの校正区間を保存します。
格子点では指定深度のN値→γ→密度の順に計算します。圧縮CSVにはN値・モデル間標準偏差・区間・γ・密度を保存します。
Nモデルはn_models/grid/、γモデルはmodels/wet・dry/、分布はgrid/へ保存します。
modelsの散布図は評価用モデルの結果です。全主要データで再学習したモデルの独立評価ではありません。
既存のgridは更新されません。次回実行で新しい実行IDに結果を保存します。
今後の改良で今回のtestを繰り返し選択に使う場合、最終性能は別の独立評価で確認します。
