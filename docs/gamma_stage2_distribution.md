# 深度を指定した二段階γ分布

F3＋深度の比較には `config/gamma/stage2_f3_distribution.json` を使います。説明変数は x・y・試料標高・深度・SolphyJ代表砂分・シルト分・粘土分の7数値変数です。出力先は `gamma_test/stage2_f3_depth/` です。

```bash
python -m module.gamma_stage2_distribution --config config/gamma/stage2_f3_distribution.json --stage all
```

設定は `config/gamma/stage2_distribution.json`。`prediction_depth_m` は地表からの深度（m、0以上）で、初期値は1.0です。

```bash
python -m module.gamma_stage2_distribution --stage all
```

深度を変更して、保存済みの最終モデルから別の平面分布を生成する場合：

```bash
python -m module.gamma_stage2_distribution --stage predict
```

数値説明変数は x・y・試料標高・深度・傾斜・曲率・SolphyJ代表砂分・代表シルト分・代表粘土分・J-SHIS AVS30。カテゴリ変数は地質（symbol由来）・JCODEです。試料標高は常にDEM地表標高−深度で計算します。SolphyJ代表物性は土壌図のSSGに基づく代表値で、深度別の粒度ではありません。

第一段階で深度を追加した `gamma_test/routed_models_depth/augmented.csv` の実測280件と疑似815件を使用します。評価時は実測だけを分割し、検証・テスト地点（空間評価ではブロックも）の疑似候補を除外して第一段階を学習部分だけで再学習します。第二段階の評価は実測テストのみです。実測のみの比較モデルも保存します。最終モデルは全1,095件で学習し、木の本数は空間評価5回で検証選択した本数の中央値です。

学習と予測は同一の地形・地質・J-SHIS・土壌付与処理を使用します。SolphyJ・AVS30の欠損はNaNを保持します。土壌ポリゴンが重複して異なるSSGになる場合も欠損とします。地質の未取得はUNKNOWN、カテゴリの未知値はone-hot全ゼロです。

出力先は `gamma_test/stage2_f4_jshis_depth/`：

- `metrics.csv`・`summary.csv`：実測テスト評価
- `training_features.csv`：全学習データと説明変数
- `final/`：最終モデル・前処理・メタデータ
- `grid_depth_1m/gamma_wet.png`：指定深度の平面分布
- `grid_depth_1m/gamma_wet.npy`・`gamma_wet.txt.gz`：10 mグリッド数値（kN/m³）
- `grid_depth_1m/chunks/`：座標・深度・標高・予測γのCSV
- `grid_depth_1m/prediction_summary.json`：完了状態・予測件数・学習深度範囲外フラグ

画像は設定の `display_spacing_m`（初期値100 m）で表示し、数値行列は10 m間隔を保持します。propマスク外はNaNです。既存の学習出力や同じ深度の分布がある場合は停止します。再学習時は設定の `output` を新しい保存先にしてください。

`--stage train` は学習のみ、`--max-chunks` は確認用の部分予測です。部分予測はincompleteとなり、最終PNGを生成しません。従来の本番パイプラインとは別の実行コマンドです。

## 今回の評価

seed 42〜46の5回平均。独立した5-fold CVではありません。

|学習条件|地点分割R²|10 km空間分割R²|
|---|---:|---:|
|実測のみ|0.1475|−0.0505|
|実測＋深度追加後の疑似γ|0.0295|−0.7081|

第一段階の深度追加による改善が、第二段階の改善を保証するものではありません。今回の空間評価では疑似γの追加が実測のみより悪化しています。全件学習モデルの木の本数は45、学習深度範囲は0.225〜51.275 mです。出力分布はこの精度評価と併せて解釈してください。

## F3＋深度との比較

全10回でF4＋AVS30＋JCODE＋深度と同じ実測分割・再生成疑似γを使用していることを照合しました。

|モデル・学習条件|地点R²|空間R²|空間RMSE（kN/m³）|
|---|---:|---:|---:|
|F3＋深度・実測のみ|0.0973|−0.0174|1.4066|
|F3＋深度・実測＋疑似|−0.0562|−0.5559|1.6633|
|F4＋AVS30＋JCODE＋深度・実測＋疑似|0.0295|−0.7081|1.7409|

F3＋深度はF4＋AVS30＋JCODE＋深度より空間評価が良い一方、地点評価は悪くなっています。疑似γ追加による改善は確認できません。F3の最終木の本数は23です。
従来の深度なしF3の疑似γ追加条件は空間R² −0.7300でしたが、今回の比較では第一段階と第二段階の両方に深度を追加しているため、第二段階の深度だけの効果とは解釈できません。

両モデルで地下1 mの全域出力が完了しました。各モデルの有効予測セルは18,517,097点、対象マスク内の未予測セルは0です。全10 mセルの予測範囲はF3＋深度が16.0149〜17.7234 kN/m³、F4＋AVS30＋JCODE＋深度が14.0036〜18.7121 kN/m³です。PNGの色範囲は各モデルで自動設定されるため、画像同士の色だけで数値を比較しないでください。
