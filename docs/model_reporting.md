# モデル作成時の必須出力

今後、機械学習モデルを作成するときは、寄与度の集計・棒グラフと学習目的値の度数分布を必ず保存します。
共通処理はmodule/model_reporting.pyのsave_model_reportsです。新しい学習経路にもこの処理を接続してください。
今回はコードのみ変更し、既存モデルの再解析・再描画・テストは実行していません。

- feature_contribution.csv / .png：元の説明変数に集約した寄与度
- feature_contribution_encoded.csv / .png：カテゴリ展開後の寄与度
- target_distribution.csv / .png：実際に学習した目的値の度数分布（20区間）
- density_distribution.csv / .png：γモデルでは目的値を密度[g/cm³]へ換算した度数分布も出力
- report_metadata.json：対象集団・件数・値域・算出方法

寄与度はXGBoostのgainを展開後の特徴量間で百分率に正規化し、元の説明変数ごとに合計します。
early stoppingを使う評価モデルでは、予測に採用した木数までで寄与度を集計します。
因果効果やSHAPではありません。図は上位30項目、CSVは全項目を保存します。
分岐に使われなかった説明変数は0として扱います。
度数は重みなしの試料・測定レコード数で、孔数や全域予測値の分布ではありません。
各図はそのモデルの学習データを使用します。評価用モデルと全データ再学習モデルでは対象データが異なります。

φ/N値・γ・cモデルAの最終モデルに加え、孔単位/空間評価、N値導入比較、N推定のseed別モデルと木数調整モデルに接続しました。
主モデルはモデル保存先、評価モデルはevaluation等、N推定ensembleはreports/seed_<番号>/に保存します。
同じ学習済みモデルを2つの条件で評価する場合、モデルとレポートは共用します。

## 全実測データとの比較（2026-09-28）

通常のφ（N値）・γ・c学習では、最終再学習モデルを使って、前処理後の全実測試料を予測する比較図を追加しました。
標準名の `observed_vs_predicted_n.png`（φ側のN値）と `observed_vs_predicted.png`（γ・c）は、この全件比較を表示します。
図のR²も同じ全件から計算し、`n`を表示します。データ点の間引きはしません。N値は従来どおり実測・予測とも上限50です。

学習に使用したデータを含む当てはまりの指標であり、独立テストの汎化性能ではありません。元のテスト図は末尾 `_test.png` に保持し、`metrics.json` の `test` およびテストCSVは変更しません。全件指標は `all_observed` に保存します。

追加出力：`all_observed_predictions.csv`、`all_observed_metrics.json`、`all_observed_r2.txt`、末尾 `_all.png` の比較図。
全件CSVは試料の元ID、座標、深度、実測値、予測値、残差を保存します。疑似目的変数を混ぜたデータは全実測比較として受け付けません。

既存結果の再作成：

```bash
python -m module.all_observed_reporting --run results/20260926/phi --target phi
python -m module.all_observed_reporting --run results/20260926/gamma_wet --target gamma_wet
```

保存済みモデルと前処理を使用し、モデルの再学習や全域分布の再計算はしません。保存された説明変数・学習件数・テスト実測値との整合性を確認します。
φ側のグラフは実測N値と予測N値の比較です。N値から換算するφを、実測φと誤記しません。

今回再作成した全件R²は、N値31,339件で0.759532、湿潤γ280件で0.887478です。最新の保存済み最終モデルが確認できた2対象を再作成しました。cは保存済み最終モデルがないため、次回学習から適用します。

## テスト・全実測の2種類の出力

分布作成には、評価で決めた木数を使い、前処理も含めて全採用データで再学習したモデルを使用します。
各学習実行で、評価モデルのテスト比較図を `_test.png`、最終モデルの全実測比較図を `_all.png` に直接保存します。
標準名の図は従来互換のため全実測比較です。全体とは前処理・対象範囲による除外後の採用データを指します。
`comparison_metrics.csv` に2種類の件数・R²・MAE・RMSE・モデルの区別をまとめます。
個別の指標は `test_metrics.json` / `test_r2.txt` と `all_observed_metrics.json` / `all_observed_r2.txt` に保存します。
cのテスト指標は `metrics.json` 内では従来どおり `evaluation.test` にあります。

## 空間検証の削除（2026-09-29）

通常のφ・γ・c学習と過去の比較実験から空間分割検証を削除しました。
通常の評価は孔単位の学習・検証・テスト分割です。全データ再学習とテスト／全実測の比較図は継続します。
比較実験は設定された各seedで孔単位分割を行います（K分割交差検証ではありません）。
疑似γ実験は `_borehole` 出力先を使い、依存する実験も孔単位の結果を参照します。
基準実験から順に再実行が必要です。過去の空間検証結果ファイルは履歴として保持し、新しい評価には使いません。
空間分布作成に必要な座標・DEM・格子の設定は変更しません。

## 比較図の深度色分け

N値・γ・cのobserved vs predicted図（全実測・テスト・N値導入比較）は、深度をviridisの連続色で表示します。カラーバーは `Depth (m)`、色の範囲は各図の有効な深度の最小値〜最大値です。深度の欠損・非数値・無限大は灰色（`Depth unknown`）で表示し、点を除外しません。既存PNGへの反映には再描画が必要です。

## φの5-fold CV出力

φは孔単位5-fold CVで評価します。全foldのR²・RMSE・MAE、平均・標準偏差、全OOF指標、最終モデルの全実測指標は、`phi/evaluation_metrics.csv` の1ファイルにまとめます。
`phi/model/` 直下は寄与度図・重要度図・全実測比較図・テスト比較図の4枚だけです。モデルや補助出力は `model/artifacts/` に保持します。
指標はSPT N値が対象です。詳細は [phi_original.md](phi_original.md#評価結果の出力) を参照してください。
