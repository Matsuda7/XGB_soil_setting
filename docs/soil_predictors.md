# c・γの説明変数（最新設定）

学習・予測ともに9変数を使用します。

| 列 | 意味 |
|---|---|
| x, y | 内部の平面座標（東西、南北） |
| sample_z | 学習：DEM地表標高−試料中央深度。予測：DEM地表標高−設定深度 |
| slope | 傾斜 |
| curvature | 曲率 |
| jshis_avs30 | AVS30 |
| symbol | 地質区分 |
| jshis_jcode | 地形区分 |
| n_input | 同じ試料標高／予測標高に対応する推定N値（上限50） |

surface_z・depthは標高を計算するための補助列として保持し、c・γの説明変数には直接入力しません。
現在の予測面の指定はprediction_depth_mです。一定標高面を直接指定する設定ではありません。
cとγはそれぞれconfig/c/model.jsonc、config/gamma/model.jsoncで管理します。
N値を推定する上流モデルは従来のconfig/phi/model.jsoncを使います。その説明変数は今回変更しません。

γは従来どおり主要試料のみでpredicted_nを学習します。比較用no_n条件ではn_inputを外します。
cは有効粘着力が得られるCŪ・CD試料を使用し、実測N値との対応有無では学習対象を限定しません。
cのN値モデル設定はconfig/c/n_estimation.jsonです。
両者とも対象孔・地域を除いた推定N値を学習側に作成し、評価孔・地域は上流N値モデルからも除外します。
全域予測では指定深度から標高を計算し、同じ標高の推定N値をc・γへ入力します。
寄与度・目的値度数分布・R²付き評価図の出力は継続します。

今回の変更後の解析・学習・テストは未実行です。既存結果は旧設定のままです。
前処理の設定署名を変更したため、次回はprepareを含む全段階を実行してください。
`python run_analysis.py --targets c gamma`


## N値条件の精度比較

現在のc・γの比較条件は `predicted_n` と `measured_n` の2つです。
`predicted_n` は学習・検証に漏洩を防いで推定したN値、`measured_n` は対応する実測N値を使います。
両条件は実測N値と対応できる同じ試料・同じ学習/検証/テスト分割で比較します。
cの比較結果は `evaluation/<検証方式>/comparison.csv`、条件別の図はその下の条件名ディレクトリに保存します。
比較用の試料が不足する場合はエラーとし、条件ごとに異なる試料へ自動変更しません。
最終分布は引き続き推定N値を使用します。cの最終学習は従来どおり全対象試料を使用し、比較のpredicted_nで決めた木の数を使います。
実測N値条件の精度は、未知地点で推定N値を使用する場合の精度そのものではありません。
過去の比較結果は削除せず、新規解析からこの条件を適用します。
