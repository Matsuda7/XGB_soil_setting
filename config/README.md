# Configuration layout

設定は共通条件と対象固有条件に分けています。値の統一や解析条件の比較は、まず共通ファイルを確認してください。

- `model.json`: φ・c・γの学習データに使う深さ範囲（上下限を含む）。`include_n50` はN値を目的変数にするφだけに適用されます。
- `prediction.json`: 共通の予測深度と空間設定ファイル。各対象の予測設定と合わせて読み込まれます。
- `spatial.json`: 格子、DEM、座標系、プロパティマスクの定義。
- `phi/`, `c/`, `gamma/`: 説明変数、対象固有の予測・評価・上流モデル設定。

予測設定の優先順位は、`spatial.json` の値、共通 `prediction.json`、対象別 `prediction.json` の順です。対象別ファイルには出力間隔やチャンクサイズなど対象固有の設定を置きます。

共通深度範囲を変更した後は、各対象の学習データ作成・学習を再実行してください。c と γ の準備済みデータは設定署名で変更を検知します。
